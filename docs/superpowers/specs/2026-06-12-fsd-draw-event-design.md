# FSD 럭키드로우 이벤트 — 설계 문서

작성일: 2026-06-12 · 상태: 사용자 리뷰 대기 · 범위: Trace 레포 (mock 기반 FE 구현)

## 1. 개요 / 목적

테슬라 모델X(FSD) 1개월 사용권을 경품으로 하는 럭키드로우 이벤트를 Trace에 구현한다.
단발 응모(버튼 1회)가 아닌 **퀘스트형 응모권 적립 + 리더보드 + 가중 추첨** 구조로,
이벤트가 Trace의 핵심 자산인 **검증된 후기 공급**을 견인하는 그로스 루프가 되도록 한다.

## 2. 확정된 결정 사항

| 결정          | 내용                                                                                                |
| ------------- | --------------------------------------------------------------------------------------------------- |
| 당첨 방식     | **가중 추첨** — 응모권 수 = 추첨 확률 가중치. 순위 확정 지급 아님 (UI에 명시)                       |
| 경품 구조     | 1등 FSD 1개월 사용권 2명 / 2등 기프티콘 5천원권 300명 / 전원 주차 할인 쿠폰 (중복 X, 최초 응모 1회) |
| 응모권 획득   | 퀘스트형 — 최초 진입 1장 + 퀘스트 달성 시 추가 적립                                                 |
| 결제 퀘스트   | Trace에 결제가 없으므로 **이용내역 인증(/verify) 퀘스트로 대체**. 추후 본진 결제 연동 시 승격       |
| 리더보드 배치 | 허브 페이지에 Top 5 프리뷰 + **별도 라우트**(`/event/fsd-draw/leaderboard`)에 전체 랭킹             |
| 작업 범위     | Trace 레포, 기존 MVVM + mock 패턴 그대로. 실 백엔드/실 추첨 로직은 비범위                           |

## 3. 퀘스트 / 응모권 모델

| 퀘스트                         | questId  | 응모권 | 반복 | 캡            |
| ------------------------------ | -------- | ------ | ---- | ------------- |
| 이벤트 최초 진입 (로그인 상태) | `enter`  | 1장    | 1회  | —             |
| 신규 회원가입                  | `signup` | 2장    | 1회  | —             |
| 후기 작성                      | `review` | 3장    | 반복 | 1일 3건       |
| 이용내역 인증 (verify)         | `verify` | 2장    | 반복 | 인증 건당 1회 |
| 친구 초대 (가입 완료 기준)     | `invite` | 2장    | 반복 | 최대 5명      |

- 후기 작성이 최고 가중(3장) — 이벤트 목적(후기 공급)에 정렬.
- 비로그인 진입 시 응모권 미적립, "로그인하면 응모권 1장" CTA로 전환 유도.
- 전원 쿠폰은 최초 응모권 적립 시점에 1회 지급된 것으로 표시.

### 허브 (`/event/fsd-draw`) 섹션 구성

1. 히어로 — LUCKY DRAW / 카피 / 응모 기간·발표일 (목업 톤 유지, 영수증 디자인 시스템 적용)
2. 경품 안내 — 1등/2등/전원 카드 (기존 목업 구조 이식)
3. 내 응모 현황 — 보유 응모권 수 + 완료/미완료 퀘스트 리스트 (퀘스트별 CTA: 후기 쓰기 → `/write`, 인증 → `/verify`, 초대 → 링크 복사)
4. 리더보드 프리뷰 — Top 5 + 내 순위 + "전체 보기" 링크
5. 유의사항 — 가중 추첨 방식 명시 ("응모권이 많을수록 확률이 올라가요. 순위가 당첨을 보장하지 않아요")

### 리더보드 (`/event/fsd-draw/leaderboard`)

- 전체 랭킹 리스트 (영수증 라인아이템 톤), 닉네임 마스킹 (`김**`)
- 내 순위 카드 상단 고정 (sticky)
- 정렬 기준: 응모권 수 desc, 동률 시 최근 적립 순

## 5. 헤더 / 내비게이션

- `AppHeader.tsx` 데스크톱 GNB에 메뉴 추가: **홈 · 검색 · 이벤트 · 내 후기** (이벤트 → `/event/fsd-draw`)
- `DockBar.tsx` (모바일)에 이벤트 탭 추가
- 이벤트 진행 중 뱃지(dot) 표시는 선택 사항 — 1차 비범위

### 적립 연동 지점 (기존 코드 후킹)

| 시점                             | 위치                                                                      | 적립                   |
| -------------------------------- | ------------------------------------------------------------------------- | ---------------------- |
| 이벤트 페이지 최초 진입 (로그인) | `useEventHubViewModel` mount                                              | `enter` 1장            |
| 회원가입 완료                    | `useSignupViewModel` 성공 콜백                                            | `signup` 2장           |
| 후기 제출 성공                   | `useWriteViewModel` submit 성공 (edit 모드 제외)                          | `review` 3장 (캡 검사) |
| 이용내역 인증 완료               | `useVerifyViewModel` 성공 콜백                                            | `verify` 2장           |
| 친구 초대                        | 허브의 초대 링크 복사 + 데모용 '가입 완료' 시뮬레이션 (DemoSwitcher 연계) | `invite` 2장 (캡 5명)  |

## 7. 엣지 케이스

| 케이스                           | 처리                                                                                |
| -------------------------------- | ----------------------------------------------------------------------------------- |
| 비로그인 진입                    | 응모권 영역을 로그인 CTA로 대체, 퀘스트는 잠금 표시                                 |
| 이벤트 기간 외                   | 시작 전: 카운트다운 + 퀘스트 비활성 / 종료 후: 응모 마감 + 발표 안내                |
| 응모권 0장 (로그인했지만 미응모) | "첫 응모권 받기" 강조 CTA                                                           |
| 후기 일일 캡 초과                | 적립 스킵 + 퀘스트 카드에 "오늘 적립 한도 도달" 표시                                |
| hydration                        | 응모권은 localStorage — 기존 패턴대로 useEffect 마운트 후 동기화 (초기값 읽기 금지) |

## 8. 비범위 (책임 경계)

- 실제 추첨 로직·당첨자 발표·제세공과금(5만원 초과 22%)·경품 고지 문구 → PM/운영 확정 영역
- 실 백엔드 API·친구 초대 실 트래킹·푸시/알림 → 본진 연동 마일스톤
- 헤더 이벤트 뱃지, 이벤트 목록 허브(`/event` 인덱스) → 후속

## 9. 검증 기준

- `pnpm type-check` / `pnpm lint` 통과
- 플로우: 로그인 → 허브 진입(+1장) → 후기 작성(+3장) → verify(+2장) → 리더보드에서 내 순위 변동 확인
- 캡 동작: 후기 4건째 적립 스킵, 초대 6명째 스킵
- 비로그인/기간 외 상태 렌더 확인
